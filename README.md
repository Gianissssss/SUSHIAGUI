# Sushi Agüi 🍣

Sitio web responsive para Sushi Agüi, con identidad visual Japanese Luxury, menú de productos, carrito de compras y presentación de servicios. Proyecto frontend desarrollado con HTML, CSS y JavaScript vanilla.

## Funcionalidades

- Navegación responsive con menú desplegable en pantallas pequeñas.
- Catálogo de productos con selector de cantidades.
- Carrito dinámico con subtotales, total y eliminación de productos.
- Formulario de pedido de demostración.
- Formulario de suscripción de demostración.
- Secciones de presentación, catering, contacto y redes sociales.
- Diseño adaptable a celulares, tablets y computadoras.
- Identidad visual Japanese Luxury: negro tinta, dorado champagne y marfil.
- Tipografías editoriales serif y sans serif, detalles dorados y jerarquía visual renovada.

## Tecnologías

- HTML5 y CSS3
- JavaScript (Vanilla)
- Bootstrap 5.3.2
- AOS (Animate On Scroll)
- Font Awesome

## Ejecutar localmente

1. Descargá o cloná este repositorio.
2. Abrí la carpeta del proyecto en Visual Studio Code.
3. Abrí `index.html` con Live Server, o abrí el archivo directamente en el navegador.

No requiere Angular, Node.js, npm ni proceso de compilación. Las bibliotecas externas se cargan desde CDN, por lo que se necesita conexión a Internet para ellas.

## Carrito y formularios

El carrito funciona en el navegador. El formulario de pedido y la suscripción son demostrativos: no envían datos a un servidor ni procesan pagos. Para recibir pedidos reales hace falta conectar un backend o un servicio de formularios y definir un método de pago seguro.

## Rendimiento

Se optimizaron imágenes grandes utilizadas en la página y se reemplazaron por WebP para reducir el peso de descarga.

## Identidad visual

La dirección visual Japanese Luxury utiliza fondos oscuros, acentos dorado champagne, tonos marfil, fotografía protagonista y tipografía editorial. La capa de estilos se encuentra en `japanese-luxury.css`, separada de los estilos previos para facilitar su mantenimiento.
